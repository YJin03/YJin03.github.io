# 한국 수출입 데이터 탐색

> **개인 연습 프로젝트 · 가상 데이터 사용**
>
> 이 프로젝트는 데이터 분석 과정을 연습하고 포트폴리오에 정리하기 위해 만든 예시입니다. 현재 포함된 데이터는 실제 무역 통계가 아닌 재현 가능한 가상 데이터이며, 실제 국가별 수출입 실적이나 경제적 결론으로 해석하면 안 됩니다.

## 1. 프로젝트 질문

- 월별 수출액과 수입액은 어떤 흐름을 보이는가?
- 품목 및 교역국별 수출입 규모는 어떻게 다른가?
- 무역수지(수출액 - 수입액)는 기간과 품목에 따라 어떻게 달라지는가?

## 2. 데이터와 분석 범위

- 데이터: 스크립트에서 생성하는 가상 월별 수출입 데이터
- 기간: 2025년 1월–12월
- 차원: 월, 교역국, 품목
- 지표: 수출액, 수입액, 무역수지
- 단위: 백만 달러(가상 수치)

실제 데이터로 확장할 때는 관세청 수출입무역통계 또는 한국무역협회 K-stat의 공개 통계를 내려받아 출처·집계 기준·단위를 확인한 뒤 교체합니다.

## 3. 분석 과정

1. Pandas로 데이터 생성 및 불러오기
2. 데이터 타입, 결측치, 중복 확인
3. 월별·국가별·품목별 집계
4. 무역수지와 증감률 계산
5. Matplotlib으로 추이 및 비교 시각화
6. 분석 결과와 한계 기록

## 4. 실행 방법

```bash
pip install pandas matplotlib
python analysis.py
```

실행하면 `data/trade_sample.csv`와 `outputs/` 폴더의 PNG 차트가 생성됩니다.

## 5. 핵심 코드와 결과물

- `analysis.py`: 가상 데이터 생성, 전처리, 집계, 시각화
- `data/trade_sample.csv`: 실행 시 생성되는 가상 데이터
- `outputs/monthly_trade.png`: 월별 수출입 추이
- `outputs/balance_by_country.png`: 교역국별 무역수지 비교

## 6. 해석 시 유의사항

가상 데이터는 코드와 시각화 흐름을 확인하기 위한 연습용입니다. 여기서 계산된 수치·순위·추세는 현실의 무역 현상을 설명하지 않습니다. 실제 공공데이터를 연결한 뒤에만 실증적인 인사이트를 작성합니다.

## 7. 사용 기술

Python · Pandas · Matplotlib · Git
